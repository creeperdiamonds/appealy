Pricing

Appealy is free.

There are no paid plans. Every server gets every feature and the same limits, and there is nothing to buy.

The limits

Every server on the shared bot has these limits. They are the same for everyone.

Limits for every server, from shared/schema/pricing.ts.
Limit Every server
Submissions per day3,000
Tickets per day1,500
Giveaway entries per day15,000
Forms per server100
Panels per server100
Roles per rule type40
Questions per form150
Submission history1,095 days (three years)
Dashboard API requests per minute600

In-server forms are capped at 25 text questions. This comes from Discord: a pop-up form holds five questions, and Appealy chains up to five pop-ups. A DM form asks one question at a time, so it can use all 150. Select questions are asked before the pop-up and do not count toward the 25.

History older than three years stops showing up and stops counting. Pending submissions are never removed, because someone is still waiting on them. The privacy policy has the details.

Self-hosting

Appealy is open source under the AGPL-3.0. You can run it yourself, and then your limits are whatever you set in your own .env.

If you paid before

Paid plans and the dedicated hosting option have been retired. If you paid for one and have questions, ask in the community server.
