Message Content intent

Appealy doesn’t use the Message Content intent. It was removed from the bot on 10 November 2026, and the bot no longer asks for it when it connects.

What used it, and what replaced it

  • Ticket transcripts were its last use. They’re gone. A closed ticket now stays in the server as a read-only channel (or an archived, locked thread), so staff can still read the conversation in Discord. Appealy doesn’t copy or store it.
  • Moderation commands are slash commands: /ban, /unban, /kick, /mute and /unmute. Moderators can also type @Appealy ban …, which works without Message Content because the message mentions the bot.
  • /poll takes its close time as a command option.
  • Applications done by DM and sticky messages never needed it: Discord sends the text of DMs to the bot, and sticky messages only count messages.
