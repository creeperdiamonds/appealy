Message Content intent

A ticket is closed and Appealy posts its transcript to the server’s transcript channel (and DMs a copy to the person who opened it). The transcript is the text of the messages sent in the ticket, which needs Message Content.

Server staff keep the transcript as a log of the support conversation, so they can check what was said after the ticket channel is deleted, for example when a member disputes a decision or appeals it later. The transcript has to include what the members wrote, not just commands, so a slash command can’t replace it.

Appealy reads the ticket channel’s messages once, when the ticket closes. The transcript is the file posted in Discord: Appealy doesn’t store message text on its own servers, and doesn’t use it for AI training.

What doesn’t use it any more

  • Moderation commands are slash commands: /ban, /unban, /kick, /mute and /unmute. The ?ban prefix commands, which read every message, have been removed. Moderators can still type @Appealy ban …, which works without Message Content because the message mentions the bot.
  • /poll takes its close time as a command option. Appealy used to ask in the channel and read the reply.
  • Applications done by DM and sticky messages never needed it: Discord sends the text of DMs to the bot, and sticky messages only count messages.
