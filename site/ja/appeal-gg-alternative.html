Appeal.gg のオープンソースな代替

どちらも Discord の BAN解除申請を扱います。一方はホスティング型の申請ポータル、 もう一方は中身を読み、fork し、自分で動かせるボットです。どちらが良いかは具体的な条件で 決まります。このページはその条件を率直に書こうとしています。

先に読んでください。Appealy はミュートや警告の異議申し立てには対応していません。 Appeal.gg は対応しています。Discord にはタイムアウトや警告に異議を申し立てるための API が ないため、それを提供している製品は自前のデータベースでそれらの処分を管理しています。これは 本物の機能であり、そちらに留まる本物の理由です。申請のうち無視できない割合が BAN 以外で あれば、ここで読むのをやめてください。Appealy は今お使いのものの代わりにはなりません。

乗り換えに持ち運ぶものはありません

Appeal.gg 用のインポートコマンドはありませんし、作ることもできません。 Appeal.gg にはデータのエクスポート機能がないからです。Appealy は競合を スクレイピングしません。Appy 用のインポーターが動くのは、Appy がエクスポートコマンドを 備えていて、そのファイルをあなたが Appealy に渡すからです。

実際には、これは聞こえるほど問題になりません。Appeal.gg が持っているのは申請で あり、処理済みの申請には先々ほとんど価値がありません。去年片付いた案件を参照することは ないからです。この点でスタッフ募集の応募とは違います。応募は本当に残しておきたい履歴で あり、だからこそAppy からの移行には本物のインポーターが 用意されています。

つまり乗り換えの手順は、Appealy を招待し、解除申請フォームを作り、解除申請をオンにする だけです。以前の申請は、そのアカウントが存在するかぎり、今ある場所でそのまま読めます。

乗り換える理由になりうるもの

  • ボットが 2 つではなく 1 つで済みます。応募やチケットや認証をすでに 使いたいと思っているなら、解除申請はそれらに付いてきて、審査キューも 1 つを共有します。
  • いつでも出ていけます。/export がすべてを JSON で書き出し、 /import-appealy が読み戻します。離脱はサポートとのやりとりではなく、 サポートされた操作です。
  • トークンを自分で持てます。セルフホスト すれば、私たちの誤った判断であなたの解除申請が止まることはありません。経路に私たちが いないからです。

乗り換えない理由になりうるもの

  • ミュートと警告。上に書いたとおりです。これがいちばん大きな点です。
  • ポータルはボットとは別物です。Appeal.gg の核にある仕組み — 招待リンクの discord.gg を appeal.gg に置き換えると、BAN されたユーザーが あなたの申請ページに着く — は本当によくできていて、サーバーがまったく見えない人にも 機能します。
  • まさにそのために作られた製品です。標準的な申請ポータルだけが必要なら、 1 つのことをする製品のほうが、9 つのことをするボットの 1 機能より、たいてい上手に こなします。

Appeal.gg は別の人たちによる別のプロジェクトで、私たちは提携していません。そちらのほうが 合うなら、そちらを使ってください。

よくある質問

Appeal.gg の申請データを Appealy にインポートできますか？

できません。Appeal.gg にはデータのエクスポート機能がないため、インポーターが読むファイルが存在せず、Appealy はほかのサービスをスクレイピングしません。実際にはあまり問題になりません。処理済みの申請には先々ほとんど価値がないからです。スタッフ募集の応募はそうではなく、だからこそ Appy からの移行には本物のインポーターがあります。

Appealy は Appeal.gg のようにミュートや警告の異議申し立てを扱えますか？

扱えません。BAN のみです。Discord にはタイムアウトや警告に異議を申し立てるための API がないため、それを提供している製品は自前のデータベースでそれらの処分を管理しています。申請の多くが BAN 以外であれば、Appealy は今お使いのものの代わりにはなりません。

Appealy は Appeal.gg と同じプロジェクトですか？

違います。別の人たちによる別のプロジェクトで、提携もしていません。Appeal.gg は BAN、ミュート、警告を扱うホスティング型の申請ポータルです。Appealy はスタッフ募集とチケットのためのオープンソースの Discord ボットで、BAN解除申請も動かし、AGPL-3.0 のもとでセルフホストできます。

あとから Appealy のデータを取り出せますか？

取り出せます。/export コマンドがサーバーのフォーム、パネル、提出、回答をすべて 1 つの JSON ファイルに書き出し、/import-appealy がそれを別のサーバーに読み戻します。

Appealy は無料ですか？

すべての機能について無料です。有料プランで上がるのはスループット上限だけです。セルフホストは AGPL-3.0 のもとで無料です。
