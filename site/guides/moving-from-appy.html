Moving from Appy

Rebuild each application as an Appealy form, post its Apply button, and, if you want, bring your old submissions across. Keep Appy until the new setup works; there’s no need to remove it first.

1. Rebuild your applications

  1. Add Appealy

    Click Add to Discord and pick your server. New to the dashboard? See Getting started.

  2. Make a form for each Appy application

    In Forms, press New form. Pick Staff application or another template, or Blank form.

    Copy your Appy questions in word for word. The history import matches old answers to questions by their exact text, so a changed word means that question’s old answers don’t come across.

  3. Set where applications go

    Pick a Log channel: that’s where new applications arrive, with Accept and Deny buttons. Roles you gave on accept in Appy go under Granted on accept.

  4. Choose pop-up or DMs

    In server asks up to 5 questions in a Discord pop-up. Direct message asks up to 10, one at a time. Pick DMs if your Appy application had more than 5 questions.

  5. Post the Apply button

    In Panels, press New panel, pick the channel your Appy panel was in, Attach a form, then Create panel and Post. One panel can hold up to 5 applications. Then delete the old Appy panel message so members use the new one.

2. Bring your old submissions (optional)

  1. Export from Appy

    In your server, run Appy’s /export_applications and save the .json file it gives you. Appy keeps submission history on its paid plan only, so a free Appy server may have nothing to export.

  2. Import into Appealy

    As the server owner, run this and attach the file:

    /import-appy application_name: Staff Application file: (your .json)

    application_name is the Appealy form to import into; it suggests your forms as you type.

  3. Check the result

    Appealy tells you how many submissions it imported. If some questions’ text didn’t match a question on your form, it says how many: those answers are left out (the submissions still come in). Fix the question text on your form and run the import again to fill them in.

Running it again is safe. Appealy remembers each Appy submission it imported and skips it the next time, so re-uploading the same file only adds what’s missing. Appy’s export doesn’t include who reviewed an application or why, so those stay empty. One file can hold up to 5,000 submissions, and if your plan can’t hold the whole file, Appealy imports nothing and tells you, rather than importing part of it.

3. Finish up

  • Send a test application yourself and check it arrives in the Log channel.
  • When everything works, you can remove the old bot in Server Settings → Integrations.
  • Want ban appeals too? Appealy has them; see Let banned members appeal.

Comparing the two first? See Appealy as an Appy alternative.

Stuck on a step? Ask in the support server, or see all guides.
