Getting started

Add the bot, open the dashboard, pick your server. About two minutes.

  1. Add Appealy to your server

    Click Add to Discord, pick your server and press Authorize. You need Manage Server on that server, or it won’t be in the list.

    Leave every permission ticked. Each one is used by a feature, and a missing one makes that feature quietly do nothing.

  2. Open the dashboard

    Go to appealy.app/dashboard. It sends you to Discord to sign in the first time: press Authorize there and you come straight back.

  3. Pick your server

    Use the server menu at the top. Servers marked UNINVITED don’t have the bot yet: pick one and press Invite Appealy.

    You only see servers where you’re the owner, an Administrator, or have Manage Server.

  4. Pick a channel for Appealy’s updates

    The first time, the dashboard asks you to Pick a channel for Appealy’s updates. Choose a staff or announcements channel and press Send updates here. Appealy posts a short note there when something important changes, nothing else.

    If it says it can’t, give Appealy the Manage Webhooks permission in that channel and try again.
